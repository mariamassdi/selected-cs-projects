
# Advanced Data Structures

Academic project developed as part of the Data Structures course at the Technion – Israel Institute of Technology.

The project focuses on designing and implementing advanced data structures in C++ and integrating them into a dynamic fleet and pirate management system, with an emphasis on algorithmic efficiency.

## Project Implementation

[View Source Code](advanced-data-structures)

### AVL Tree

- Generic, template-based implementation.
- Self-balancing binary search tree.
- Tree rotations and height maintenance.
- Insertion, deletion, and search operations.
- Minimum and maximum element retrieval.

### Hash Table

- Custom template-based hash table.
- Collision handling using AVL trees.
- Dynamic resizing and rehashing.
- Element insertion, removal, and lookup.

### Union-Find (Disjoint Set)

- Path compression.
- Union by size.
- Dynamic fleet merging.
- Additional rank and offset tracking during merge operations.

## System Functionality

- Dynamic management of fleets and pirates.
- Fleet merging and membership queries.
- Pirate ranking and salary management.
- Integration of multiple data structures.
- Input validation and error handling.
